## PhaseCast input contract (verbatim element list)

From [`src/cnmineral/data/tokens.py`](https://raw.githubusercontent.com/matthew-j-liu/phasecast/main/src/cnmineral/data/tokens.py) (main branch, fetched 2026-11-25), the tokenizer vocabulary is 22 element tokens plus one optional redox token:

- **MAJORS (9):** Si (Z=14), Al (13), Ca (20), Mg (12), Fe (26), K (19), Na (11), Ti (22), Cr (24)
- **TRACES (13):** Sr (38), Zr (40), Ba (56), Y (39), Rb (37), Ni (28), Nb (41), V (23), La (57), Ce (58), Nd (60), Yb (70), Th (90)
- **Optional 23rd token:** `REDOX_TOKEN_ID = 120` — Fe³⁺/total-Fe cation ratio, populated only where a measured feo+fe2o3 pair exists.

The user-facing CSV contract ([`docs/tutorial/README.md`](https://raw.githubusercontent.com/matthew-j-liu/phasecast/main/docs/tutorial/README.md) + [`inference_helpers.py`](https://raw.githubusercontent.com/matthew-j-liu/phasecast/main/docs/tutorial/inference_helpers.py)):

- CSV with **lowercase** oxide columns. **Required majors:** `sio2 al2o3 cao mgo k2o na2o tio2` (oxide wt%) **plus one of** `feo`+`fe2o3` / `feo_tot` / `fe2o3_tot`. **Optional:** the 13 traces as `<sym>_ppm`.
- **Blank and 0 both mean not-measured.** Below-detection values are left blank, not zero-filled.
- **Nothing is renormalized — do not rescale to 100 wt%.** `cr2o3`, `MnO`, `P2O5`, `LOI`, and totals columns are ignored.
- `check_input` **errors:** fewer than 4 measured elements; any oxide outside 0–100; any trace outside 0–1e6 ppm. **Warnings:** a missing major; majors total outside 85–103 wt%.
- Tokenizer internals ([`bulk_chemistry.py`](https://raw.githubusercontent.com/matthew-j-liu/phasecast/main/src/cnmineral/data/bulk_chemistry.py)): oxides convert to cation wt% by fixed factors (sio2 ×0.4675, feo ×0.7773, fe2o3 ×0.6994, …); majors tokenize as cation wt%/100, traces as ppm/1e6; exact 0 → missing; Fe fallback chain `feo+fe2o3 → feo_tot → fe2o3_tot`.

**Run path (verified against the tutorial and repo):** checkpoints are git-tracked — `checkpoints/pretrain_allrock_redox_seed0/epoch_best.pt` (~44 MB) and `checkpoints/joint_heads_allrock_tuned_seed0/heads_best.pt` (~7 MB). `JointHeadCheckpoint.load` → `load_encoder_from_checkpoint(ckpt.encoder_checkpoint)` → `predict(rocks, encoder, heads)` → `card(record)`. Run from repo root (the heads checkpoint stores the encoder path relative to root); on macOS import `cnmineral` before `torch`. Inference needs **no Julia/MAGEMin** — CPU only, ~15 ms/rock for a 512-sample posterior. The tutorial already parses ALS/Actlabs-style exports.

## Distribution limits and OOD behavior

**The honest OOD story for a skarn, from the repo's own files:**

- **Labels are volcanic-only.** The 1.07M-label simulated corpus ([Zenodo README](https://zenodo.org/api/records/23992951/files/README.md/content), verified) was generated by MAGEMin only on volcanic compositions: SiO₂ ≤ 80, MgO ≤ 18, oxides sum ≥ 90, foidites excluded.
- **But the encoder is all-rock.** Pretraining used 787,721 measured compositions spanning igneous + sedimentary + metamorphic (min 4 populated tokens) — so tokenization/encoding of a skarn composition is in-distribution even though the mineralogy heads are not.
- **Measured OOD benchmark exists and shows degradation, not collapse.** The repo's plutonic zero-shot benchmark (575 evaluated rocks; [`explorations/real_mineralogy`](https://raw.githubusercontent.com/matthew-j-liu/phasecast/main/explorations/real_mineralogy/README.md), [`plutonic_zero_shot.json`](https://raw.githubusercontent.com/matthew-j-liu/phasecast/main/explorations/real_mineralogy/results/joint_heads_allrock_tuned_seed0/plutonic_zero_shot.json)): joint NLL −1.456 vs climatology −4.257 — **+2.80 nats over null, vs +10.63 on the volcanic benchmark**. Per-group AUROC: px 0.779, amp 0.764, ol 0.831, q 0.997, bi 0.485, opq 0.462 (fsp n/a). Share MAE 0.019–0.104.
- **The journal flags a "metamorphic-drift regime"** below the wet solidus ([`docs/journal.md`](https://raw.githubusercontent.com/matthew-j-liu/phasecast/main/docs/journal.md)): no T window is both calibrated and subsolidus for hydrous dacite. A sedimentary-transfer exploration measured **net-worse** on 605 real XRD rocks.
- **Skarn signature minerals are in the vocabulary but outside the scored heads.** The 21-phase vocab ([`phase_vocab.py`](https://raw.githubusercontent.com/matthew-j-liu/phasecast/main/src/cnmineral/data/phase_vocab.py)) includes garnet (g), epidote (ep), muscovite (mu), sphene (sph), Al₂SiO₅ polymorphs — but these 11 phases are outside the 7 scored groups and **never benchmarked against real modes**. Scheelite/powellite are not in the vocab at all; actinolite only scores via the "amp" proxy.

**Implication for the local play:** PhaseCast will run cleanly on a Trumbull amphibolite or granitoid analysis (borderline-acceptable, as a "hypothetical igneous equivalent"), will run but be unvalidated on skarn/tactite and schist, and cannot see scheelite mineralization at all. Pair every run with MAGEMin (thermodynamic ground truth) and treat PhaseCast output on local rocks as a hypothesis generator, never a determination. This matches the prior calibration note: restrict interpretation to immobile elements (Ti, Zr, Nb, Y, REE) when metasomatism is suspected.

## Local data sources

All query flows below were exercised with real requests this session.

1. **USGS NGDB Rock** — [mrdata.usgs.gov/ngdb/rock/find-rock.php](https://mrdata.usgs.gov/ngdb/rock/find-rock.php), POST `state=fUS09` → **643 CT records, 558 with coordinates, 83 within ~41.0–41.6 N / −73.5 to −72.8 W.** Closest to the park: **BCT198 / BCT199 / BCT204 at 41.335, −73.189** (field RWLH22, "dump or prospect pit", mineralization "replacement", paleozoic) — essentially at Old Mine Park. Per-sample pages (e.g. [`show-ngdbrock.php?lab_id=BCT198`](https://mrdata.usgs.gov/ngdb/rock/show-ngdbrock.php?lab_id=BCT198)) return full element tables: 1970 E-Spec semiquantitative spectrograph data, Mg/Ca/Ti/Fe as wt%, ~30 traces in ppm, W reported as N50 (<50 ppm). **Caveat:** this is semi-quantitative 6-column spectrograph data, not modern certified whole-rock majors, and it lacks the full PhaseCast major-oxide set. (The sibling ground-truth report additionally identifies BCT196, a tactite at 41.291, −73.23 with W 200 ppm; its session recorded 1265 CT samples from the same portal — the count differs from this session's 643, so re-query before relying on either total. Per-sample pages are the stable artifact either way.)
2. **NURE-HSSR stream sediment** — [mrdata.usgs.gov/nure/sediment/find-nuresed.php](https://mrdata.usgs.gov/nure/sediment/find-nuresed.php), POST `state=fUS09` → **643 records across all 8 CT counties** (New Haven 80, Fairfield 73). Per-sample pages carry W (e.g. <2 ppm), Th, U, and 40+ elements. Whole-country CSV download `nuresed-csv.zip` (37.6 MB) available. Good for a watershed-scale W/anomaly map around Trumbull; not whole-rock.
3. **GEOROC** — [georoc.eu/georoc/GeographCoord.asp](https://georoc.eu/georoc/GeographCoord.asp): the lat/lon box search **works** (41.0–42.0 N / −73.5 to −72.5 W → 256 data rows; location-name search "AVALON ZONE;APPALACHIANS" → 3571 rows). **But the download path is broken server-side as of 2026-11-25:** the refinement step `SampCont.asp` throws `Invalid object name 'qryROCK_NAME'` (error '80040e37', line 174) and `Select.asp` throws `Incorrect syntax near the keyword 'AND'` (error '80040e14', line 248) for every parameter combination tried (~30). This is parameter-independent — do not retry; report as "search works, download broken." No "Trumbull" or "Connecticut" location name exists in GEOROC's list.
4. **EarthChem/PetDB** — the old PetDB at [search.earthchem.org](https://search.earthchem.org) is **offline** (PHP 5 security notice, no restore timeline). **PetDB 2.0 at [earthchem.org/petdb](https://earthchem.org/petdb) is live** with a map/filter search UI — the right place to check for modern whole-rock analyses of the Straits Schist / Pinewood Adamellite at regional scale.
5. **Historical literature (OpenAlex, fetch-verified)** — Shannon, E. V. (1920), "Some minerals from the old tungsten mine at Long Hill in Trumbull, Connecticut," *Proc. U.S. National Museum* 58(2348):469–482, [doi.org/10.5479/si.00963801.58-2348.469](https://doi.org/10.5479/si.00963801.58-2348.469); and a 1921 *American Mineralogist* piece, ["The old tungsten mine in Trumbull, Connecticut"](https://pubs.geoscienceworld.org/msa/ammin/article-6/8/126). Both are mineralogical, not bulk-geochemical. 2021/2022 Western CT Alleghanian/Acadian papers (Pinewood adamellite, Permian hydrothermal veins) reference Old Mine Park in full text.

**Bottom line:** the only geochemistry at the park itself is sparse 1970s USGS E-Spec data; the best modern-analogue compositions for the local play are regional PetDB 2.0 / GEOROC amphibolite and granitoid analyses, plus NURE sediment for the W-anomaly context.

## Tool runnability

| Tool | Verdict | Verified install path |
|---|---|---|
| **PhaseCast** | **Runnable today** | Clone [github.com/matthew-j-liu/phasecast](https://github.com/matthew-j-liu/phasecast) (MIT); checkpoints in git; CPU inference, no Julia needed; ~15 ms/rock. Paper: [arXiv:2610.36429](https://arxiv.org/abs/2610.36429) (NeurIPS 2026 Sim2Science). Use `submission` branch to reproduce paper numbers; `main` is later research. |
| **pyrolite** | **Runnable** | [PyPI 0.3.9](https://pypi.org/pypi/pyrolite/json), `pip install pyrolite`, requires Python ≥3.11 (PhaseCast's own env pins 0.3.6 for py3.10). Use for CoDA transforms/renormalization *before* PhaseCast — but remember PhaseCast wants un-normalized input. |
| **MAGEMin** | **Runnable, three ways** | (a) Julia: [MAGEMin_C.jl](https://computationalthermodynamics.github.io/MAGEMin_C.jl/dev/); (b) MAGEMinApp GUI (`julia Pkg.add MAGEMinApp`, serves 127.0.0.1:8050); (c) new Python wrapper [`magemin`](https://pypi.org/pypi/magemin/json) (PyPI 0.1.3, `pip install magemin` + `magemin-install` downloads prebuilt binaries, **requires Python ≥3.14**, wraps the official C API via ctypes; repo [ondrolexa/MAGEMin_py](https://github.com/ondrolexa/MAGEMin_py)). Databases include Metabasite (Green 2016), Metapelite (White 2014), Igneous (Green 2025) — suitable for skarn-relevant bulk compositions. This is the thermodynamic ground-truth partner for the play. |
| **Thermobar** | **Runnable but mismatched** | [PyPI 1.0.75](https://pypi.org/pypi/Thermobar/json), [PennyWieser/Thermobar](https://github.com/PennyWieser/Thermobar), has a streamlit app. **Needs mineral EPMA analyses, not whole-rock** — unusable for the local play without microprobe data. |
| **OpenGADBench / GeoChemAD** | **Runnable** | [github.com/yihaoding/geochemad](https://github.com/yihaoding/geochemad) (MIT), bundled GSWA/GSC data, 10 tasks, `pip install -r requirements.txt`. Use as the OOD/anomaly check when feeding local compositions to any model. |
| **GeoGalactica** | **Skip** | Prior runs established it as a dormant artifact with prompt-following failures — it contributes the tool-calling *idea*, not a working component ([design report](geogalactica-phasecast-together-2026-11-25.md)). |
| **PetroMind, craton, GEM, cross-domain-seismic-fm, geopredict, critical-mineral-ml** | **Skip** | Imagery/seismic/prospectivity ML from the initial scan — none take whole-rock geochemistry input. |
| **GemPy / LoopStructural** | **Skip** | 3D structural modeling; no geochemical contract. |

**Recommended local-play stack:** pyrolite (prep) → PhaseCast (hypothesis) → MAGEMin (ground truth) → OpenGADBench-style OOD check, with USGS NGDB/NURE + PetDB 2.0 as data.

## Predictions

1. **PetDB 2.0 will return few or no Trumbull-specific whole-rock analyses.** The locality literature (Shannon 1920 onward) is mineralogical, not bulk-geochemical. *Falsified if* an earthchem.org/petdb search at the park coordinates returns modern certified whole-rock majors for Old Mine Park / Straits Schist samples.
2. **The Python `magemin` wheel will fail on a default macOS Python** (3.9–3.13) because it requires ≥3.14; the Julia `MAGEMin_C.jl` / MAGEMinApp paths will work on the same machine. *Falsified if* `pip install magemin && magemin-install` succeeds on Python <3.14, or if the Julia install fails where the wheel works.
3. **PhaseCast will accept a Trumbull skarn/tactite whole-rock analysis through `check_input` without errors** (warnings at most, since skarn CaO/SiO₂ extremes may push the majors total), and will produce a fluent posterior that assigns ~zero mass to garnet/epidote assemblages and none to scheelite — i.e., the failure mode is silent plausibility, not rejection. *Falsified if* `check_input` hard-rejects skarn compositions, or if the posterior surfaces garnet/epidote with meaningful mass.

**Open question (1):** does any modern certified whole-rock analysis of the Trumbull skarn itself exist anywhere? The only in-situ geochemistry found is 1970s USGS E-Spec semi-quantitative data lacking the full PhaseCast major-oxide set.
