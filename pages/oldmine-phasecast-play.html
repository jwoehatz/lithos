Running PhaseCast on my local rocks

A practical guide to the only latent-space mineralogy model in existence — what it eats, what it can and cannot see, where local geochemistry actually comes from, and the theory behind the one rule that governs every run: never read its output as the mineralogy of the rock in your hand.

Verdict. PhaseCast is runnable today on a laptop, in about 15 milliseconds per rock, with no Julia and no GPU. But its mineralogy predictions were trained on volcanic rocks only, and the rocks at Old Mine Park are metamorphic and metasomatic. So every local run is read one way: as a hypothesis about the protolith — the igneous rock these rocks used to be — never as a description of what they are now. The model cannot see scheelite at all, and has never been benchmarked on garnet or epidote.

1. What PhaseCast eats: the input contract

PhaseCast takes a whole-rock geochemical analysis — the kind a commercial lab prints on a certificate — and returns a probability distribution over mineralogy and formation conditions. Getting numbers in the door is the part people get wrong, so the contract comes first.

The elements it knows, verbatim from the tokenizer (source: src/cnmineral/data/tokens.py, fetched 2026-11-25):

GroupElementsHow they enter
Majors (9)Si, Al, Ca, Mg, Fe, K, Na, Ti, CrAs oxide weight percent: sio2 al2o3 cao mgo k2o na2o tio2 plus one of feo+fe2o3 / feo_tot / fe2o3_tot
Traces (13)Sr, Zr, Ba, Y, Rb, Ni, Nb, V, La, Ce, Nd, Yb, ThAs ppm, one column each named <sym>_ppm
Redox (optional)Fe³⁺/total-Fe ratioOnly where a measured feo+fe2o3 pair exists

The rules that matter, in practical language:

  • Column names are lowercase oxides. sio2, not SiO2. The parser is case-sensitive and unforgiving.
  • A blank and a zero mean the same thing: "not measured." This is the single most important rule. If your lab reports tungsten as "<50 ppm", you leave the cell blank. Zero-filling a below-detection value tells the model a confident lie: it converts "we couldn't see it" into "we measured it and it isn't there."
  • Never renormalize to 100%. Every geochemist's reflex is to close a composition to 100 wt%. Here it corrupts the input. The model wants the analysis exactly as the lab printed it. If the majors total 91% because the rock has 9% volatiles, that's information, not an error.
  • MnO, P₂O₅, LOI and totals are ignored. Don't bother cleaning them up.
  • The input checker (check_input) hard-rejects fewer than 4 measured elements, any oxide outside 0–100, or any trace outside 0–1e6 ppm. It warns on a missing major or a majors total outside 85–103 wt%. Warnings are fine; errors stop the run.

Practical shortcut: the tutorial ships a parser for ALS and Actlabs certificate exports. If your data comes from either lab, the bridge from PDF certificate to model-ready CSV already exists.

2. How to actually run it

No installation ceremony. The model weights are committed directly in the git repository — not on HuggingFace, not as LFS pointers, real files:

  • checkpoints/pretrain_allrock_redox_seed0/epoch_best.pt — ~44 MB (encoder, includes optimizer state)
  • checkpoints/joint_heads_allrock_tuned_seed0/heads_best.pt — ~7 MB (mineralogy heads)

Clone, load, predict. The run path, verified against the tutorial:

git clone https://github.com/matthew-j-liu/phasecast
# load: JointHeadCheckpoint.load → load_encoder_from_checkpoint → predict(rocks, encoder, heads) → card(record)

Three practical gotchas:

  1. Run from the repo root. The heads checkpoint stores the encoder path relative to the root; run it from elsewhere and the load fails.
  2. On macOS, import cnmineral before torch. Load-order matters.
  3. Use the submission branch to reproduce the paper's numbers. The main branch holds later research and its numbers differ — the README says so explicitly.

Inference needs no Julia and no MAGEMin (those are only for retraining). CPU only, ~15 ms per rock for a 512-sample posterior. The output "card" per rock is a posterior distribution over mineral assemblages and formation conditions — not a single answer, a spread of them with probabilities.

3. What it can and cannot see

This is where the model's honesty is unusual and worth quoting. The author's own files disclose every weakness below; nothing here is inference.

CapabilityStatusEvidence
Encoding any rock compositionWorks. The encoder was pretrained on 787,721 measured compositions spanning igneous, sedimentary and metamorphic. A skarn analysis is in-distribution at the token level.Zenodo corpus README, verified
Mineralogy predictions on volcanic rocksStrong. +10.63 nats over climatology on the volcanic benchmark.repo benchmark tables
Mineralogy predictions on plutonic rocksDegraded, not collapsed. Zero-shot scores +2.80 nats (vs +10.63). Per-group AUROC 0.46–0.83 — pyroxene and amphibole roughly coin-flip.plutonic_zero_shot.json, 575 rocks
Mineralogy predictions on metamorphic rocksUnvalidated. The author's journal flags a "metamorphic-drift regime" below the wet solidus: no temperature window is both calibrated and subsolidus. A sedimentary-transfer test was net-worse on 605 real XRD rocks.docs/journal.md
Garnet, epidote, muscovite, spheneIn the vocabulary, never scored. These 11 phases sit outside the 7 benchmarked groups. Predictions for them exist but have never been checked against reality.phase_vocab.py
Scheelite, powelliteInvisible. Not in the 21-phase vocabulary at all. The model cannot output them under any input.phase_vocab.py
External baselinesNone. The paper states verbatim: "no external method is evaluated." No XGBoost, no CIPW norm, no classical thermobarometry comparison. The author's own issue tracker keeps the baseline task open (#95).arXiv:2610.36429; issue #95

The trap, stated once and binding: feed PhaseCast a Trumbull skarn and it will not refuse. It will accept the composition, run cleanly, and hand back a fluent, confident-looking posterior describing an assemblage that never existed in that rock — because the minerals that are there (garnet, epidote, scheelite) are outside what it was ever taught to say. The failure mode is silent plausibility, not rejection. This is the unscored prediction on file from the 2026-11-25 run; the skarn run itself has not been executed yet.

4. The theory: the igneous equivalent of a protolith

Every practical rule above flows from one idea. This section is the idea.

4.1 Metamorphism is (mostly) a closed system

When a basalt is buried to 28 kilometers and heated past 650 °C — which is exactly what happened to the rocks at Old Mine Park during the Acadian orogeny — its atoms do not leave. Metamorphism is recrystallization, not replacement: the same chemical budget rearranges into new minerals stable at the new pressure and temperature. Basalt's plagioclase and pyroxene reorganize into amphibolite's hornblende and plagioclase. The minerals change; the whole-rock chemistry — the element budget a lab measures when it pulverizes the sample — is inherited essentially unchanged.

The exceptions are the volatile species (H₂O, CO₂), which escape and are measured as loss-on-ignition, and — where hot fluid flows through — the mobile major elements. Hold that thought; it is the hinge of the whole argument.

4.2 Composition is a fossil

Because the element budget is inherited, a whole-rock analysis of a metamorphic rock is a chemical fossil of its protolith — the rock it was before metamorphism. This is not a new idea; it is the working principle behind a century of protolith reconstruction. Geochemists run the same discrimination diagrams on amphibolites that they run on basalts (Ti/Zr ratios, Zr/Y, REE patterns) precisely because those numbers survive metamorphism intact. The amphibolite at Old Mine Park still carries, in its bulk chemistry, the memory of the mid-Ordovician seafloor basalt it used to be.

4.3 What PhaseCast actually computes

PhaseCast learned a mapping: composition → mineralogy. But it learned that mapping almost entirely from igneous compositions, with mineralogy labels simulated by MAGEMin for volcanic systems. It has no concept of "this rock was metamorphosed." It does not know what a P-T path is. It knows one story: a magma of this composition crystallized, and here is what it became.

So when you feed it an amphibolite analysis, the honest reading of its output is:

"If a magma with this whole-rock composition had cooled as an igneous rock, here is the assemblage and the conditions it would have crystallized at."

That is the hypothetical igneous equivalent of the protolith. It is a statement about the rock's past, reconstructed through the only lens the model owns. It is not, and cannot be, a statement about the hornblende-and-plagioclase rock in your hand.

This is why the framing is legitimate rather than a dodge: protolith reconstruction is a real, standard geologic task, and PhaseCast is a fast probabilistic first pass at it. The posterior over mineralogy and formation conditions is a quantitative hypothesis about what the rock was before the Acadian buried it — which is genuinely useful, as long as you remember which question you asked.

4.4 Where the theory breaks — and it does, locally

Break one: metasomatism is not metamorphism. The 4.1 argument assumes a closed system. Skarn formation — the Trumbull scheelite event, tied to the Permian Pinewood Adamellite at 291 ± 4 Ma — is the opposite: hot, silica- and fluorine- and tungsten-rich fluid from the granite surgically replaced a carbonate host. Wholesale chemistry change. A tactite's composition describes no igneous rock that ever existed; it is a metasomatic precipitate. Worse, the elements the fluid moved most (Ca, Si, K, Na) are exactly the mobile majors PhaseCast weights most heavily, while the elements that do survive metasomatism untouched — Ti, Zr, Nb, Y, the REEs — are the traces. Hence the standing rule: where metasomatism is suspected, interpret through the immobile elements only. They are the sole witnesses to the protolith; everything else may have been rewritten.

Break two: assemblage depends on history, not just composition. An igneous rock's minerals are set by crystallization from its own melt. A metamorphic rock's minerals are set by its bulk composition plus its pressure-temperature path plus whatever fluid passed through. Two rocks with identical chemistry and different histories end up with different minerals. PhaseCast knows only one history — crystallization — so even on a perfectly preserved (non-metasomatized) metamorphic composition, its answer is the igneous branch of the tree, not the branch the rock actually took.

Break three: vocabulary blindness. The model cannot output what it was never taught. Garnet and epidote are in its vocabulary but outside the scored heads — predictions exist but have never been checked against a real mode. Scheelite and powellite are absent entirely. When the true answer is outside the vocabulary, the model does not say "unknown"; it fills the gap with the most plausible in-vocabulary answer. That is the mechanism behind silent plausibility: not a bug, but the structural consequence of a fixed output space.

Break four: the calibration regime. The author's own journal notes the model's temperature calibration assumes melt-present conditions; below the wet solidus there is no temperature window that is both calibrated and physically consistent. Every metamorphic rock at Old Mine Park lives below that solidus. The "formation conditions" on the output card are the igneous equivalent's conditions, and even then only inside the calibrated regime.

4.5 Why pair it with MAGEMin

MAGEMin is the thermodynamic ground truth: a Gibbs-energy minimizer that, given a bulk composition, pressure and temperature, computes the equilibrium assemblage from first principles — including metamorphic databases (Metabasite, Metapelite) that cover exactly the P-T range the Acadian imposed. It was also the label generator for PhaseCast's training data, which makes the pairing natural: PhaseCast is the student; MAGEMin is the teacher. The student-vs-teacher comparison — same input, both outputs, where they diverge and why — is playbook item 3, and it is the check that keeps the igneous-equivalent framing honest. Where the student's posterior agrees with the teacher's metamorphic equilibrium, the protolith hypothesis gains ground. Where they diverge, you have located either metasomatism or model failure — and both are findings.

5. Local data: what exists and what doesn't

The hard reality: no modern whole-rock analysis of the park's rocks is publicly available. Every query below was exercised with real requests in the 2026-11-25 session.

But it's 1970 semi-quantitative 6-column spectrograph data — ~30 traces in ppm, a few majors as wt% — and it lacks the full major-oxide set PhaseCast requires.

The practical play is regional analogues — well-studied amphibolite and granitoid compositions from PetDB/GEOROC-class sources (the Bronson Hill arc data, 94 samples with full majors + traces, is saved locally as data/BronsonHill_WR_data.csv) — plus NURE sediment for the tungsten context.

The pipeline, in one line:

pyrolite (prep) → PhaseCast (hypothesis) → MAGEMin (ground truth) → OpenGADBench-style OOD check

7. The protocol for every run

  1. Feed it the lab certificate as-is. Lowercase oxides, blanks stay blank, no renormalization, no zero-filling.
  2. Read the output as a protolith hypothesis. The posterior describes the igneous equivalent of the rock's former self — never the rock in hand.
  3. Check the hypothesis against MAGEMin with the appropriate metamorphic database. Student vs. teacher; agreement strengthens the hypothesis, divergence locates metasomatism or model failure.
  4. Where metasomatism is suspected — skarn, tactite, any rock the Pinewood fluid touched — trust only the immobile elements: Ti, Zr, Nb, Y, REE. Everything else may have been rewritten by the fluid.
  5. Never ask it about scheelite. It cannot see it, cannot say it, and will not warn you. Tungsten mineralization lives entirely outside its vocabulary.
  6. Run the OOD check before trusting any posterior: a fluent answer outside the trustworthy range is the most dangerous kind.

One open question on file: does a modern, certified whole-rock analysis of the Trumbull skarn exist anywhere — private lab archives, a thesis, a state survey bulletin? Everything publicly reachable says no. Finding one would upgrade the entire local play from analogue-based to direct.
